# Contributing to MK ScorpioSec Research

## How to Contribute

**Methodology questions or corrections:** Open an issue using the Methodology Question template.  
**Additional findings:** Open an issue using the Additional Finding template — include scanner output, file reference, and severity.  
**New research studies:** Open a Discussion in the Research category first.

## Research Standards

All contributions must meet the same bar as published studies:
- Findings reproducible from publicly available tools (Trivy, Checkov, pq-audit, TruffleHog)
- Evidence provided as raw tool output (JSON preferred)
- No client or proprietary data — lab/intentionally-vulnerable repos only

## Commit Signing

All commits to `main` must be GPG signed.
